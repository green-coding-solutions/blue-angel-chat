Could your software get the Blue Angel?

Enter the URL of a software product. An AI agent researches the product page, privacy policy, support pages, source code and web search results, then checks all 21 criteria of the Blauer Engel für Software (DE-UZ 215).

You can watch every step live. Each criterion is rated Verified Maybe Not possible with comments and evidence. Afterwards you can answer open questions in the chat and the agent updates its assessment.

This is an automated first check, not an official audit by RAL.
